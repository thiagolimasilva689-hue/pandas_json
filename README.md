# 📚 Livros - Pandas + JSON

Projeto de análise de livros usando Python, Pandas e JSON.

## 📊 Análises realizadas
- Média de páginas
- Filtro de livros lidos
- Livro mais antigo
- Contagem de livros por autor
- Exportação e leitura de JSON

## 🛠️ Tecnologias
- Python 3
- Pandas
- JSON

## 📁 Arquivos
| Arquivo | Descrição |
|---------|-----------|
| `livros.py` | Código principal |
| `livros.json` | Dados exportados em JSON |

## 🚀 Como usar
```bash
pip install pandas
python livros.py
